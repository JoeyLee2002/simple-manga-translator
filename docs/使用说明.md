# 简单漫画翻译器

## 开始使用

1. 新建项目，填写项目目录。
2. 打开“引擎设置”，选择 DeepSeek，填写 API 地址、模型名称和自己的 API 密钥。
3. 导入原稿。支持图片、PDF、CBZ、ZIP，也可粘贴文件夹路径；多个路径每行一个。
4. 点击“开始/继续翻译”。任务可停止，完成的页面会保存，下次可继续。
5. 逐页核对译文，修改后点击“保存并更新预览”。
6. 点击“导出PDF”，选择保存路径。

## 修改文字

- 点击文字区，在右侧编辑原文和译文。
- 拖动文字框可以移动位置，拖动右下角可调整大小。
- Ctrl 多选文字区后可合并；Ctrl+Z 撤销，Ctrl+S 保存。
- 右键拖动可添加文字框，Ctrl+滚轮缩放，PageUp/PageDown 翻页。
- 字号可选自动，也可直接输入数值。
- 拟声和标识默认保留。需要翻译时将类型改为“对白/旁白”。

## 识别与翻译

英文OCR和中英OCR在本地运行。云端视觉OCR使用所填服务的图片接口，适合日文或复杂页面；服务需支持图片输入。

在“术语/背景”填写固定译名及故事背景。已有译文不会在继续任务时自动覆盖；“重译选区”只处理所选文字。

“二次识别查漏”会列出候选文字，可添加或忽略。数字、否定词、艺术字和复杂背景建议逐页核对。

## 项目与输出

项目目录中的 project.json、images、pages 应一起备份。原稿副本、文字、译文和排版都保存在项目内。

导出前会检查漏译、重叠和越界。成功后生成PDF、译文CSV与检查报告。复杂背景的清字效果和翻译语义需要人工核对。

程序设置保存在 `%LOCALAPPDATA%\MangaTranslatorStudio`。勾选“记住密钥”后按Windows账户加密保存。普通OCR模式只发送识别出的文字；云端视觉OCR会发送整页图片。
